Three steps, that's all

From install to your first dictation in under two minutes.

Install & choose an engine

Download Sonora, open the Settings (⚙ icon on the bar), pick a provider and paste your API key (or point to a local Whisper model).

Press the shortcut

The floating bar appears and dictation starts. A sound wave confirms Sonora hears you.

Text lands at your cursor

Release: the text is typed where you were working, or copied to the clipboard. Reformulate it if needed with your prompts.

Frequently asked questions

Everything you need to know before your first dictation.

Is Sonora free?

Yes — Sonora is 100% free and open-source under the MIT license. No account, no subscription. Bring your own API key for cloud engines, or run everything locally for free with Whisper.

Does Sonora work offline?

Yes. With the built-in local Whisper engine (ggml), transcription runs entirely on your machine — no API key, no internet, and nothing leaves your computer.

Which platforms does Sonora support?

macOS (Apple Silicon & Intel), Windows and Linux. Sonora ships as a lightweight native binary built with Tauri.

Is Sonora an open-source alternative to Wispr Flow, superwhisper or Dragon?

Yes — Sonora is a free, cross-platform, privacy-first alternative to voice-dictation tools like Wispr Flow, superwhisper and Dragon NaturallySpeaking. You choose your engine (Gemini, Mistral, OpenAI, Groq or any OpenAI-compatible endpoint) or run fully local Whisper.

Are my API keys and dictations private?

Your API keys live in the OS keychain, never in plaintext. Audio is sent only to the provider you pick — or nowhere at all with local Whisper.

Can Sonora type directly where I'm working?

Yes — Sonora types the text straight at your cursor, or copies it to the clipboard. On Linux it uses wtype (Wayland) or xdotool (X11); on macOS it needs the Accessibility permission.
